# NBA Elo

This file contains links to the data behind [The Complete History Of The NBA](https://projects.fivethirtyeight.com/complete-history-of-the-nba/) and our [NBA Predictions](https://projects.fivethirtyeight.com/2020-nba-predictions/).

`nba_elo.csv` contains game-by-game Elo ratings and forecasts back to 1946.
`nba_elo_latest.csv` contains game-by-game Elo ratings and forecasts for only the latest season.

> **Note (2026):** FiveThirtyEight's NBA forecast ended with the 2022-23 season, and following ABC News's shutdown of FiveThirtyEight, `https://projects.fivethirtyeight.com/nba-model/` and the NBA predictions pages now redirect to `https://abcnews.go.com/politics`. The Internet Archive keeps copies of [`nba_elo.csv`](https://web.archive.org/web/20250306125344id_/https://projects.fivethirtyeight.com/nba-model/nba_elo.csv) and [`nba_elo_latest.csv`](https://web.archive.org/web/20250306125344id_/https://projects.fivethirtyeight.com/nba-model/nba_elo_latest.csv) (both end with the 2023 Finals). For the current season, [Clutch](https://clutchledger.com/data/) publishes a free CC BY 4.0 CSV in the same column layout (team1 at home, FiveThirtyEight's team codes) with a pregame win probability for every game.
